# 10을 이용해 빼기 (tentaker)

초등학교 1학년 **받아내림이 있는 뺄셈**(14−9, 13−8 …)을
교과서의 '10을 이용해 빼기' 방법으로 연습하는 웹앱입니다.
덧셈 짝꿍 앱은 [10을 만들어 더하기 (tenmaker)](https://jihye84.github.io/tenmaker/)예요.

👉 **바로 쓰기: https://jihye84.github.io/tentaker/**

## 세 가지 방법

| 방법 | 예 | 이렇게 풀어요 |
|---|---|---|
| 낱개 빼기 | 14−4 | 14를 10과 4로 가르고, 낱개 4개를 빼면 10 |
| 빼는 수 가르기 | 14−9 | 9를 4와 5로 갈라, 낱개 4개를 먼저 빼고 10개 묶음에서 5개를 마저 빼기 |
| 빼지는 수 가르기 | 14−9 | 14를 10과 4로 갈라, 10개 묶음에서 9개를 빼고 남은 1과 낱개 4를 더하기 |

빼는 수(9)를 누르면 '빼는 수 가르기',
빼지는 수(14)를 누르면 '빼지는 수 가르기'로 풀어요.
답을 알면 단계를 건너뛰고 **최종 답 칸에 바로** 써도 돼요.

## 기능

- **연결모형 블록**
  - 처음에는 14개가 한 덩어리로 붙어 있다가,
    '14는 10과 4'를 맞히는 순간 10개 묶음과 낱개로 갈라져요.
  - 뺀 블록은 날아가지 않고 **제자리에 빗금 친 흐린 흔적**으로 남아,
    무엇을 몇 개 뺐는지 눈으로 확인할 수 있어요.
  - 하나씩 천천히 빗금이 쳐져 아이들이 세면서 볼 수 있어요.
  - 답 단계에서는 남은 블록에 금색 테두리가 생겨요.
  - 블록을 콕 누르거나 틀 밖으로 끌어내서 직접 뺄 수도 있어요.
- **가르기 그림**: 교과서처럼 화살표와 빈칸으로 보여 줘요.
- **손글씨 인식**: 칸 안에 손가락으로 숫자를 쓰면 알아봐요.
  인터넷 연결 없이 기기 안에서 인식해요.
- **숫자판·키보드**: 숫자판은 화면 아래쪽에 있어요.
  숫자 키(숫자 패드 포함)로 쓰고, **스페이스 바**로 다음 문제로 넘어가요.
- **힌트**: 두 번 틀리면 세어 볼 블록이 깜빡여요.
- **설정(⚙)**
  - 빼는 방법: 스스로 고르기 / 빼는 수 가르기 / 빼지는 수 가르기 / 번갈아
  - 문제 종류: 받아내림(14−9) / 낱개 빼기(14−4) / 섞어서
  - 빼는 수(9, 8, 7, 6, 5), 문제 직접 내기, 소리 켜기·끄기
- 휴대폰·태블릿·노트북·교실 TV·전자칠판 어느 화면에서도 스크롤 없이 한 화면에 보여요.
- 카카오톡·네이버 등 앱 안에서 열면 기본 브라우저로 다시 열려요
  (아이폰은 'Safari로 열기' 안내가 떠요).

## 손글씨 인식 모델과 자료 출처

숫자 인식에는 직접 학습시킨 작은 합성곱 신경망(CNN)을 씁니다
(tenmaker와 같은 모델). 가중치는 `index.html` 안에 들어 있습니다.

- 학습 자료: **MNIST 손글씨 숫자 데이터베이스**
  (Yann LeCun, Corinna Cortes, Christopher J.C. Burges)
  - 그중 일부를 담은 [cazala/mnist](https://github.com/cazala/mnist) 패키지 (MIT License)
  - 그중 일부를 담은 [mlxtend](https://github.com/rasbt/mlxtend) `mnist_data` (BSD 3-Clause License)
- 검증 정확도 약 98.8% (MNIST 자료 기준). 어린이 글씨에서는 더 낮을 수 있어요.
  자신 없는 글씨는 "다시 써 볼까요?"라고 다시 묻습니다.
